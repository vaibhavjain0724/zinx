What is Zinx?

Zinx is a small Lisp-inspired programming language built in vanilla JavaScript.

Zinx uses square brackets [ ] for expressions and statements.

Basic Syntax

Zinx uses prefix notation. The operator or command comes before its arguments. 

[+ 5 10]

is equivalent to:

5 + 10

Output

Use show to display a value. 

[show 10]

Output:

10

Arithmetic

[+ 5 10]
[- 10 5]
[* 5 2]
[/ 10 2]

Arithmetic expressions return a value. They do not produce visible output by themselves.

Nested Expressions

Expressions can be used inside other expressions. 

[+ 5 [* 2 3]]

Result:

11

Nested expressions can also be passed to show. 

[show [+ 5 [* 2 3]]]

Output:

11

Division by Zero

Division by zero is a runtime error in Zinx. 

[/ 10 0]
