Language reference

Write small programs with Zinx.

Zinx is a small, Lisp-inspired programming language built in vanilla JavaScript. Use the playground to write code, inspect tokens and the AST, and run a program one statement at a time.

Try the playground → Read the guide

01

Basic syntax

Expressions use familiar infix operators: the operator goes between two values.

Zinx
show (5 + 10) * 2
Output30

Parentheses group an expression and override normal operator precedence. Programs can contain several statements; they run from top to bottom.

02

Values

Every expression evaluates to a value.

TypeExampleNotes
Integer42Whole numbers are used in arithmetic.
Booleantrue, falseUsed as conditional tests.
String"Hello"Double quoted; supports \n, \t, \", and \\.
VariablescoreStarts with a letter or _; may contain digits and _.

03

Output

Use show to display the result of an expression.

Zinx
show 5 + (2 * 3)
show "Hello, Zinx!"
Output11 Hello, Zinx!

An expression on its own evaluates but does not add anything to the output panel.

04

Variables

Use set to create a variable or replace its current value.

Zinx
set score 72
set score score + 8
show score
Output80

Variables can be used wherever an expression is expected. Reading a name before it has been set raises an error.

05

Operators

Operators combine two expressions and return a new value.

KindOperatorsExample
Arithmetic+ - * /10 / 2
Equality== !=name == "Zinx"
Comparison> < >= <=score >= 50

Arithmetic and ordering comparisons require integers. Equality works with integers, booleans, and strings. Precedence is multiplication/division, addition/subtraction, then comparisons.

06

Conditionals

Choose which statement to run with if and else.

Condition requiredThe expression inside if ( ... ) must evaluate to true or false.
Zinx
set score 72
if (score >= 50) (show "Pass") else (show "Try again")
OutputPass

Only the selected branch is executed. Wrap the branch statement in parentheses, as in (show "Pass"). The else branch is optional.

07

Comments

Use // to leave notes in source code.

Zinx
// This runs through the end of the line.
set message "Ready"
show message
OutputReady

08

Errors

Zinx reports an error instead of silently guessing what a program means.

Undefined variable

show total

Undefined variable: total

Division by zero

show 10 / 0

Division by zero is a runtime error.

09

Using the editor

The playground makes each stage of running a program visible.

  • Run resets program state and runs the complete program.
  • Step runs one statement and retains state until the code changes.
  • Cmd/Ctrl + Enter runs the program; Tab inserts four spaces.
  • The Tokens and AST panels expose the lexer and parser output.

10

Language status

Zinx is actively evolving. These are the features currently available in the interpreter.

Available now

  • Integers, booleans, and strings
  • Variables and reassignment
  • Arithmetic and comparisons
  • Comments and conditionals
  • Step-by-step execution

Planned next

  • Loops
  • Functions
  • Bytecode compiler
  • Zinx virtual machine
