What is Zinx?

Zinx is a small Lisp-inspired programming language built in vanilla JavaScript.

Zinx uses familiar infix arithmetic and parentheses ( ) for grouping expressions.

Basic Syntax

Zinx uses infix notation: operators go between their left and right values. 

5 + 10

Parentheses can override the normal operator precedence.

(5 + 10) * 2

Output

Use show to display a value. 

show 10

Output:

10

Arithmetic

Zinx supports four basic arithmetic operations. 

5 + 10
10 - 5
5 * 2
10 / 2

Arithmetic expressions return a value. They do not produce visible output by themselves.

Nested Expressions

Expressions can be used inside other expressions. 

5 + (2 * 3)

Result:

11

Nested expressions can also be passed to show. 

show 5 + (2 * 3)

Output:

11

Comparison

Comparisons return true or false. 

show 5 == 5
show 5 != 4
show 5 > 4
show 5 < 4
show 5 >= 5
show 5 <= 5

Output:

true
true
true
false
true
true

Equality works with integers and booleans. Ordering comparisons (>, <, >=, and <=) require integers. 

set enabled true
show enabled == false

Output:

false

Booleans

Boolean values are true and false. They can be displayed directly or stored in variables. 

show true
show false
set active true
show active

Output:

true
false
true

Strings

Strings use double quotes. They can be displayed, stored in variables, and compared with == or !=. 

show "Hello, Zinx!"
set greeting "Hello"
show greeting
show greeting == "Hello"

Output:

Hello, Zinx!
Hello
true

Use \" for a quote, \\ for a backslash, \n for a newline, and \t for a tab. String concatenation and ordering comparisons are not implemented yet.

Variables

Variables store values that can be used later

Zinx uses set to create a variable. 

set x 5

This creates a variable named x and stores the value 5.

Displaying a Variable

Use the variable name with show. 

set x 5
show x

Output:

5

Using Variables in Arithmetic

Variables can be used inside arithmetic expressions. 

set x 5
show x + 10

Output:

15

Changing a Variable

Calling set again with the same variable name updates its value. 

set x 5
set x 20
show x

Output:

20

Multiple Variables

set x 5
set y 10
show x + y

Output:

15

Multiple Statements

Zinx programs can contain multiple statements. Each statement is written separately. 

set x 10
show x
show x + 5

Output:

10
15

Statements are executed in order.

Division by Zero

Division by zero is a runtime error in Zinx. 

show 10 / 0

Undefined Variables

Using a variable that has not been defined produces an error. 

show y

Example error:

Undefined variable: y

How Zinx Works

     Lexer

The environment stores variables and their values during program execution.
